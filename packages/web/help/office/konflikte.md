# Abgleich

Hier steht, was dieses Gerät mit dem Server abgleicht: wann zuletzt, was noch wartet, und was der Server nicht angenommen hat. Eine abgelehnte Änderung hält alles auf, was danach auf diesem Gerät erfasst wurde, bis du entscheidest.

- „Jetzt abgleichen“ oben schickt, was wartet, ohne auf die nächste Runde zu warten.
- Hat jemand anderes denselben Eintrag geändert, wählst du „Fassung vom Gerät übernehmen“ oder „Stand im System behalten“.
- „Erneut senden“ schickt eine abgelehnte Änderung noch einmal. Das hilft nur, wenn der Grund inzwischen behoben ist, etwa ein Recht, das gefehlt hat.
- „Änderung verwerfen“ nimmt eine abgelehnte Änderung von diesem Gerät. Im System bleibt der Eintrag, wie er ist.
- „Eintrag verwerfen“ nimmt einen neuen Eintrag samt seinen späteren Änderungen von diesem Gerät. Im System war er nie, danach ist er ganz weg.
