# Fristen

Eine Frist ist ein Tag, an dem etwas fällig wird, weil vorher etwas geschehen ist: ein Angebot ging hinaus, eine Anlage wurde geprüft, eine Abnahme unterschrieben. Von Hand legt niemand eine an, die Fristen-Engine leitet sie ab.

Hier steht alles, was ansteht, filterbar nach Art, Kunde und Person. Was bei Fälligkeit geschieht und wie lange vorher erinnert wird, legst du unter [Einstellungen, Fristen](/einstellungen/fristen) fest.
