# Mitarbeiter

Hier steht die Mitarbeiterakte jeder Person im Betrieb: Stammdaten, vereinbarte Arbeitszeit, Qualifikationen mit Ablaufdatum und der Nachweis als Datei. Die Akte sieht nur, wer das Recht dazu hat.

Läuft eine Qualifikation ab, etwa eine Unterweisung, erinnert die Fristen-Engine vorher daran.
