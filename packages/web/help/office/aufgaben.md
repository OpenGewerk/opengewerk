# Aufgaben

Eine Aufgabe ist, was jemand zu einem Tag erledigen soll: von Hand angelegt oder von der Fristen-Engine, etwa „Angebot nachfassen“. Die fällige Aufgabe erreicht die verantwortliche Person am Morgen per E-Mail oder Push, wenn sie das eingeschaltet hat.

## Schritt für Schritt

1. Eine Aufgabe anlegen, mit Titel, Tag und wer sie erledigt, auf Wunsch an einem Auftrag.
2. Erledigte Aufgaben abhaken. Eine Aufgabe aus einer Frist erledigt dabei auch die Frist.
