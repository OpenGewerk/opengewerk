# Hilfe

Hier stehen die Kurzanleitungen zu den wichtigsten Abläufen, eine Suche über die Texte der Seiten im Büro, die Kurzanleitungen und die Versionshinweise, und was mit jeder Fassung neu ist. Das Handbuch steht im Bereich der Instanz, die Texte der Baustelle im Menü auf dem Telefon.

Zu jeder Seite gibt es einen eigenen Text. Das Fragezeichen in der Kopfleiste öffnet ihn neben der Seite, auf einem schmalen Bildschirm steht „Hilfe zu dieser Seite“ im Menü.
