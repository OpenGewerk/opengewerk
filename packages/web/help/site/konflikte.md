# Konflikte

Was der Server nicht angenommen hat, und wie es weitergeht.

Hier steht, was der Server nicht angenommen hat. Bis du entscheidest, geht nichts hinaus, was danach auf diesem Gerät erfasst wurde.

- Hat jemand im Büro denselben Eintrag geändert, wählst du „Fassung vom Gerät übernehmen“ oder „Stand im System behalten“.
- Lehnt der Server eine Änderung ab, lies, warum. „Erneut senden“ schickt sie noch einmal, sobald der Grund behoben ist.
- „Änderung verwerfen“ nimmt sie von diesem Gerät, im System bleibt der Eintrag, wie er ist. „Eintrag verwerfen“ nimmt einen neuen Eintrag ganz weg, im System war er nie.
