# Scannen

Material und Anlagen über ihren Code finden.

Halte die Kamera auf das QR-Etikett einer Anlage. Das Gerät öffnet ihre Seite mit Aufbau, Protokollen und Dateien.

Im Regiebericht und im Lieferschein scannst du auf dieselbe Weise die EAN eines Artikels. Kennt das Gerät die EAN nicht, trägst du das Material von Hand ein.
