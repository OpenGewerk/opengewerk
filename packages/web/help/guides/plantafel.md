# Termine auf der Plantafel

Aufträge den Leuten im Betrieb zuteilen, Termine verschieben und sehen, wer Urlaub oder Bereitschaft hat.

## Schritt für Schritt

1. Die Plantafel öffnen. Sie zeigt eine Woche, auf Wunsch vier.
2. Einen Termin für einen Auftrag anlegen, mit Person, Tag und Uhrzeit, oder als Serie über mehrere Tage.
3. Einen Termin verschieben oder einer anderen Person geben. Wer ihn hat, bekommt auf Wunsch eine Push-Nachricht.
4. Urlaub und Krankheit stehen in der Zeile der Person. Wer Bereitschaft hat, steht in der Zeile darüber.

## Auf der Baustelle

Unter „Termine“ sieht jede Person ihre eigenen, auch ohne Netz. Mit dem Kalender-Abo unter „Konto“ stehen sie im eigenen Kalender.
